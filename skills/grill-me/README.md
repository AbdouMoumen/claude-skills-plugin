# grill-me

This skill is based on Matt Pocock's public skills repository and adapted in this repo.

- **Original source:** <https://github.com/mattpocock/skills/tree/main/skills/productivity/grill-me>
- **Repository:** <https://github.com/mattpocock/skills>

## Local adaptations

Compared to the upstream `grill-me` skill, this repo adds:

- A rule to stay on the current topic when the user's answer includes caveats, clarifications, or follow-up questions.
- Expanded research guidance to ground recommendations using available sources (codebase, web, docs).
- SQL decision-tracking instructions (`grill_decisions`) to persist resolved decisions across the session.
